# Catálogo editorial

marvel-616-editorial-1.0.1

Marvel Comics, Terra-616; síntese editorial de caracterizações recorrentes, não um estado atual ou versão do MCU.

Avaliações interpretativas, não pontuações oficiais ou medidas psicológicas. Sem associação entre semelhança e valor moral.

Lista fechada fornecida no escopo do projeto, com validação de identidade por slug e nome. Links Marvel são referências de identificação; não são fontes de pontuações. Sem consulta a API em produção.
